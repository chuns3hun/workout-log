# 9주차 — 주제 분석 기록

## 1. 후보 비교

7주차에 정한 운동 기록 앱에서 시작해 세 가지 안을 비교했다.

| 기준 | A. 운동 기록 앱 (7주차) | B. 현장 대체 루틴 앱 | C. 주간 목표 계획 앱 (선택) |
|---|---|---|---|
| 해결하는 문제 | 지난 기록이 기억나지 않음 | 기구가 차 있으면 루틴이 꼬임 | 계획이 매일 틀어짐 |
| 기존 앱과 겹치는 정도 | 높음. 대부분의 운동 앱 기본 기능 | 높음. Hevy, 플랜핏에 이미 있음 | 조사한 범위에서는 낮음 |
| 내가 직접 겪는 문제인가 | 그렇다 | 그렇다 | 그렇다 |
| 5주 안에 구현 가능한가 | 쉬움 | 보통 (루틴 구조 + 대체 처리) | 보통 (주 단위 계산 필요) |
| 내년 응용 과목으로 확장 | 그래프, 통계 정도 | 대체 종목 추천 | 목표 조정, 부위 균형 분석, 기록 그래프 |

- A는 문제가 확실하지만 교수님 피드백대로 흔하다
- B는 처음 떠올린 해결책인데, 조사해 보니 이미 있는 기능이었다
- C는 B의 문제를 계속 파고들다가 나온 안이다. 대체 기능이 있어도 결국 "정해진 순서"가 있으면 매일 틀어진다는 점은 그대로라서, 순서를 없애고 목표만 남겼다

7주차에 같이 냈던 후보(과제 마감 관리, 오답 노트)는 내가 꾸준히 겪는 문제가 아니라서 이번에도 다시 보지 않았다.

## 2. 문제 분석

**내 경험**
- 사람이 많은 저녁 시간에는 루틴 첫 종목 기구가 차 있는 경우가 많다
- 기다리기 애매하면 다른 운동부터 하게 되고, 그러면 뒤 순서도 다 바뀐다
- 컨디션에 따라 그날 하고 싶은 운동도 다르다
- 이렇게 바꾼 날은 원래 계획과 맞지 않는 운동을 하게 되고, 이번 주에 가슴을 몇 세트 했는지 같은 건 기억으로만 남는다

**원인**
- 계획이 "어떤 순서로 무엇을 할지"로 되어 있어서, 순서 하나가 틀어지면 계획 전체가 틀어진 것처럼 느껴진다
- 내가 실제로 지키고 싶은 건 순서가 아니라 "이번 주에 각 부위를 충분히 했는가"이다

**그래서 앱이 바꾸려는 것**
- 계획 = 순서가 아니라 부위별 주간 목표
- 순서는 그날 상황에 맞게 아무렇게나 해도 되고, 목표를 채웠는지만 보이면 된다

**성공했다고 볼 기준**
- 계획이 틀어진 날에도 운동을 이어 간다
- 그런 주에도 부위별 목표를 채운 것을 확인한다
- 기록이 쌓이면서 같은 종목의 무게나 횟수가 늘어난 것을 직전 기록으로 확인한다

## 3. 유사 앱 조사

조사일: 2026-11-02. 공식 기능 설명과 앱스토어 설명, 내가 써 본 경험을 기준으로 했다.

| 앱 | 계획 방식 | 운동 중 종목 변경 | 부위별 주간 확인 | 근거 |
|---|---|---|---|---|
| Hevy | 내가 만든 루틴 (순서 있음) | 가능 (순서 변경, 대체, 삭제) | 부위별 주간 세트 수 통계 있음 | 공식 기능 페이지 |
| 플랜핏 | 목표에 맞춰 AI가 루틴 추천 | 기구를 다른 사람이 쓰고 있을 때 대체 운동을 알려 준다고 설명 | 설명에 없음 | 앱스토어 설명 |

**써 본 경험 (2026년 2학기)**
- Hevy: 직전 기록은 잘 보여 준다. 다만 없는 종목이 많았고, 종목을 직접 추가하는 데 한도가 있어 더 추가하려면 결제가 필요했다
- 플랜핏: 루틴을 내 방식대로 분할해서 구성하기가 어려웠다

**조사하면서 확인한 것**
- 운동 중에 종목을 바꾸는 기능은 이미 있다 → 처음 생각한 B안은 차별점이 되지 못한다
- Hevy의 부위별 주간 세트 통계는 운동이 끝난 뒤 보는 기록이다. 운동하는 중에 "이번 주에 얼마나 남았는지"를 기준으로 계획하는 방식은 아니다
- 플랜핏은 계획을 AI가 정해 준다. 내가 원하는 건 계획을 직접 정하는 것이다

**확인하지 못한 것**
- Hevy에서 운동 중 종목을 바꾸면 저장된 루틴도 바뀌는지
- Hevy의 종목 추가 한도와 결제 조건이 지금도 같은지 (내 사용 경험 기준이라 바뀌었을 수 있음)
- 이번에 조사한 두 앱 외에 같은 방식을 쓰는 앱이 있는지

## 4. 판단과 범위 조정

| 판단 | 이유 |
|---|---|
| 운동 주제 유지 | 교수님이 유지는 괜찮다고 하셨고, 매주 직접 겪는 문제라 내년까지 이어 가기 좋음 |
| 차별점을 "현장 대체"에서 "주간 목표"로 변경 | 대체 기능은 이미 다른 앱에 있음. 내가 겪는 문제의 원인은 순서가 고정된 계획 자체에 있음 |
| 직전 기록 표시는 남김 | 성장을 확인하는 건 여전히 내가 원하는 것. 다만 핵심가치가 아니라 보조 기능으로 둠 |
| 몸 변화 기록은 제외 | 내가 바라는 결과이긴 하지만, 체중이나 사진은 이번 가치(목표를 지키는 계획)와 직접 이어지지 않음 |
| 운동 추천 기능은 제외 | 계획을 내가 직접 정하는 것이 이 앱의 방향이라, 추천은 오히려 반대 방향 |
| 첫 작업을 "남은 목표 표시 + 세트 기록"으로 정함 | 차별점이 바로 드러나는 부분부터 만들어야 이 방향이 맞는지 빨리 확인할 수 있음 |

**개인 실험 저장소(workout-app) 정리**
- 10월에 개인적으로 만들어 본 운동 앱이 있다. 루틴, 캘린더, 통계, 식단 기능까지 넣었다
- 이번 과제에서는 이 코드를 이어 쓰지 않는다
  - 기능 대부분이 이번에 제외하기로 한 것들(통계, 캘린더, 식단)이다
  - 7주차에 정한 범위(setState, 외부 패키지 없이 시작)와 맞지 않는다
- shared_preferences로 기록을 저장해 본 경험은 12주차 저장 작업에 참고한다

## 6. 작업 방식

- 유사 앱 조사와 문서 정리에 AI(Claude)를 사용했다
- B안이 이미 있는 기능이라는 점과 계획 단위를 주간 목표로 바꾸자는 안은 AI 조사 결과에서 나왔고, 내 경험(순서가 매일 틀어짐)과 맞아서 채택했다
- 교수님 확인 내용과 내 경험은 내가 직접 정리한 내용이다
