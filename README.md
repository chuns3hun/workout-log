# Workout Log

Flutter로 만드는 웨이트 트레이닝 기록 앱입니다. (앱프로그래밍기초 개인 앱 프로젝트)

## 목적
운동할 때 종목별 무게와 횟수를 빠르게 기록하고, 직전 기록을 확인해 점진적 과부하를 관리합니다.

## 핵심 기능
- 종목별 무게·횟수 기록
- 같은 종목의 직전 기록 확인
- 날짜별 기록 목록 조회

## 화면 구성 (초안)
1. 홈: 오늘 기록 목록 + 기록 추가 버튼
2. 기록 입력: 종목, 무게(kg), 횟수 입력 / 직전 기록 표시
3. 기록 조회: 종목별 필터링

## 데이터 모델 (초안)
| 필드 | 타입 | 설명 |
|---|---|---|
| exercise | String | 종목명 |
| weight | double | 무게(kg) |
| reps | int | 횟수 |
| date | DateTime | 기록 날짜 |
