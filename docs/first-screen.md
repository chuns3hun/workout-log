# 첫 화면 — 이번 주 목표

## 1. 화면 구상

한 화면 위쪽에는 부위별 이번 주 진행 상황, 아래쪽에는 세트 기록 칸을 둔다.
운동하면서 기록하고 바로 위에서 남은 세트가 줄어드는 걸 볼 수 있게 했다.

| 구분 | 내용 | PRD 연결 |
| --- | --- | --- |
| 정보 | 부위별 이름, 진행 막대, "한 세트 / 목표 세트" | F1 |
| 정보 | 남은 세트 수, 목표를 채우면 "목표 달성" | F1, AC1, AC6 |
| 정보 | 예시 데이터라 앱을 끄면 기록이 사라진다는 안내 | 8절 데이터 |
| 조작 | 종목 고르기 (순서 없이 아무 종목이나) | F2, 핵심 가치 1 |
| 조작 | 무게, 횟수 입력 후 기록 버튼 | F2 |
| 반응 | 저장하면 그 종목 부위의 한 세트가 1 늘고 남은 세트가 1 줄어든다 | F2, AC2 |
| 반응 | 종목을 안 골랐거나 무게·횟수가 범위를 벗어나면 저장하지 않고 입력칸 아래에 안내 | F2, AC4 |
| 반응 | 저장 후 횟수 칸은 비우고 무게는 남겨 둔다 (다음 세트도 같은 무게인 경우가 많음) | F2 |

## 2. 9주차 스케치와 달라진 점

| 9주차 | 10주차 구현 | 이유 |
| --- | --- | --- |
| ① 현황, ② 세트 기록, ③ 종목 선택을 각각 다른 화면으로 나눔 | 한 화면에 현황 + 종목 선택 + 기록을 같이 둠 | 첫 주에는 핵심 행동(기록하면 남은 세트가 줄어듦)을 한 화면에서 바로 확인하는 게 우선이라서. 화면을 나누는 건 직전 기록이 들어가는 11주차에 다시 정한다 |
| 종목 선택이 목록 | 종목을 칩(ChoiceChip)으로 한 번에 보여 줌 | 순서 없이 아무 종목이나 고른다는 걸 화면에서 바로 보이게 하려고 |

## 3. 데이터 상태

| 항목 | 상태 |
| --- | --- |
| 부위별 목표 (가슴 12, 등 12, 하체 9, 어깨 9, 팔 6) | 코드에 넣은 예시 데이터 |
| 종목 8개 | 코드에 넣은 예시 데이터 |
| 처음 보이는 기록 (가슴 8세트, 하체 10세트) | AC1, AC6 확인용 예시 기록 |
| 새로 입력한 기록 | 메모리에만 저장. 앱을 끄거나 새로고침하면 사라짐 |
| 외부 연동 | 없음 |

## 4. 코드 설명

- `lib/main.dart` 한 파일, `StatefulWidget` + `setState`
- `doneSets(part)`: 이번 주 월요일 0시 이후 기록 중 그 부위 기록 수를 센다
- `remainingSets(part)`: 목표 − 한 세트. 0보다 작으면 0으로 바꿔서 음수가 안 나오게 한다
- 한 세트, 남은 세트는 따로 저장하지 않고 기록 리스트에서 매번 계산한다 (5주차 STATE_CONTRACT 원칙)
- `_saveSet()`: `tryParse`로 숫자 변환, 범위 확인 후 통과했을 때만 기록 리스트에 추가

## 6. 미완료와 11주차 작업

**이번 주에 하지 않은 것**
- AC3 (지난주 기록 제외): 주 시작 계산은 코드에 있지만 날짜를 바꿔서 확인하는 건 11주차에 한다
- AC5 (목표 없음 안내): 목표 설정 화면이 생기는 11주차에 한다
- 직전 기록 표시, 종목 추가, 목표 설정 (F3~F5)
- 기기 저장 (F6, 12주차)

**11주차 첫 작업**
- 종목을 고르면 직전 기록이 보이게 하기 (F4)
