## 1. 중간발표 의견과 PRD 반영

중간발표에서 따로 받은 의견은 없었다. 대신 발표 장표를 만들면서 PRD와 앱을 맞춰 본 내용을 정리했다.

| 구분 | 내용 |
| --- | --- |
| PRD에 반영 | 장표에만 있던 15주차 시연 목표 4가지를 PRD 12장에 넣었다. F6 설명과 완료 기준(F6-1~5)도 추가했다 |
| 확인할 질문 | "부위별 주간 목표로 바꾸면 빠진 부위가 줄어든다"는 가정을 어떻게 보여 줄지. F6이 생겼으니 한 주 동안 실제로 써 보고 그 기록으로 비교한다 |
| 이번에는 반영하지 않음 | 목업에만 있던 "남은 날 표시", "기록 완료 알림", 세트 기록을 별도 화면으로 빼는 것. 핵심 가치와 직접 상관이 적고, 실제로 쓰려면 저장이 먼저였다 |

장표를 만들다가 목업에 실제 앱에 없는 기능("남은 날 4일", 기록 완료 알림)을 넣은 걸 발견해서 발표 전에 뺐다. 현재 구현과 목표를 섞어 보여 주지 않으려고 했다.

## 2. 이번에 구현한 사용자 행동: F6 기기 저장

이전에는 모든 데이터가 메모리에만 있어서 앱을 끄면 처음 상태로 돌아갔다. 15주차에 "일주일 동안 실제로 쓴 기록"으로 시연하려면 저장이 꼭 필요했다.

- 종목, 주간 목표, 세트 기록을 바뀔 때마다 기기에 저장하고, 앱을 켜면 불러온다.
- `shared_preferences` 패키지를 썼다. 안드로이드는 SharedPreferences, 웹은 브라우저 localStorage에 들어간다.
- 처음 실행하면 기본 종목과 기본 목표로 시작하고 세트 기록은 비어 있다.
- 저장된 값이 깨져 있으면 앱이 멈추지 않고 기본값으로 시작한다.
- 커밋: [063057d](https://github.com/chuns3hun/workout-log/commit/063057d)

## 3. 프로젝트 정책과 스킬

| 종류 | 경로 | 내용 |
| --- | --- | --- |
| 정책 | [GEMINI.md](../GEMINI.md) | 작업 전에 PRD와 구현 현황 읽기, 요구사항 하나만 고치기, 새 패키지는 이유부터 설명하기, 제출이 끝난 week 폴더 수정 금지, 미실행 검사를 통과로 쓰지 않기 |
| 스킬 | [.agents/skills/prd-check/SKILL.md](../.agents/skills/prd-check/SKILL.md) | 요구사항 하나를 PRD와 대조하고 테스트와 직접 확인 결과로 IMPLEMENTATION.md를 갱신하는 절차 |

수업 예시를 그대로 쓰지 않고 이 앱에 맞게 바꿨다. PRD가 `docs/` 안에 있는 것, 요구사항 ID가 F1~F6인 것, 화면 확인은 내가 직접 하고 결과를 알려 주는 것을 넣었다.

안티그래비티(IDE)에서 새 대화를 열고 세 번 요청했다.

| 요청 | 적용 결과 |
| --- | --- |
| ① PRD·코드 대조, 계획만 | `GEMINI.md`와 prd-check를 읽었다고 답했다. 정책대로 `shared_preferences`를 넣기 전에 이유와 영향(바뀌는 파일, 웹·안드로이드 지원)을 먼저 설명하고 승인을 기다렸다 |
| ② 구현 | 계획을 읽다가 처음 실행할 때 예시 기록(가슴 8세트, 하체 10세트)까지 저장되는 문제를 찾았다. 그대로 두면 15주차에 보여 줄 실제 기록에 가짜 기록이 섞인다. 처음엔 기록을 비우고 예시 기록은 테스트에서만 쓰게 바꿔 요청했다. Chrome 확인용 포트 고정도 같이 요청했다 |
| ③ prd-check 스킬로 확인 | 스킬 파일을 읽고 F6-1~5마다 코드 위치와 테스트를 짝지어 정리했다. 내가 알려 준 Chrome 결과를 넣어 IMPLEMENTATION.md를 고쳤고, 확인한 장치(Chrome)와 안 한 장치(안드로이드), 화면에서 안 본 항목(F6-5)을 나눠 적었다 |

정책을 줬는데도 지켜지지 않은 부분이 있었다. ② 구현이 끝났을 때 AI가 IMPLEMENTATION.md에 F6을 "확인 완료, 남은 일 없음"으로 적었다. 그때 확인한 건 테스트용 가짜 저장소(mock)뿐이고 실제 브라우저에서 껐다 켜 본 적은 없었다. 그 상태로는 커밋하지 않고, 직접 확인한 뒤 ③에서 스킬 절차대로 다시 적게 했다. 정책과 스킬은 기준을 알려 줄 뿐이고, 결과는 내가 코드와 문서를 열어서 확인해야 한다는 걸 이번에 느꼈다.

③에서 AI는 스킬 경로를 `prd-check/SKILL.md`로만 말했다. 실제 경로는 `.agents/skills/prd-check/SKILL.md`다.
